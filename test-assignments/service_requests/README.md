# Тестовое задание: Заявления на услуги 📋

Отчёт по заявлениям в определённых статусах за заданный период.

---

## Задача

Сформировать отчёт по заявлениям, находящимся в статусах 3 и 4,
поданным с 01.05.2025 по 15.05.2025 (вкл),
по услугам 600775 и 664361.

### Выводимые поля

| № | Поле | Источник |
|---|------|----------|
| 1 | Номер заявления | order_hist.order_id |
| 2 | Дата подачи | order_hist.request_date |
| 3 | Код услуги | order_hist.service_passport_id |
| 4 | Идентификатор статуса | status_hist.status_id |
| 5 | Текущий статус | order_status.name |
| 6 | Дата текущего статуса | status_hist.status_date |
| 7 | Регион | splog_xml.region (последнее событие request) |
| 8 | Подразделение | splog_xml.department (последнее событие request) |

---

## Нюансы

- Не по каждому заявлению есть данные в `splog_xml`
- По заявлению может быть несколько событий `request` — в отчёт попадает **последнее**
- Для выбора последнего события используется `ROW_NUMBER() OVER (PARTITION BY order_id ORDER BY log_date DESC)`

---

## Стек

- **CTE** для разбиения запроса на логические блоки
- **ROW_NUMBER()** для выбора последней записи в группе
- **JOIN**: фильтрация статусов через `INNER JOIN` (не `WHERE` после `LEFT JOIN`)
