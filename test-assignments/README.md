# Тестовые задания 📝

Решённые тестовые задания по SQL из реальных собеседований.

---

## Структура

| Папка | Описание | Задач |
|-------|----------|-------|
| `loan_analytics/` | Аналитика займов: клиенты, регионы, платежи, просрочки | 8 |
| `service_requests/` | Отчёт по заявлениям: фильтрация, последнее событие, справочники | 1 |


---

## Как использовать

Каждая папка содержит:
- `schema.sql` — `CREATE TABLE` + тестовые данные
- `task_*.sql` — решения с условиями в комментариях

## Темы

- JOIN (INNER, LEFT)
- Фильтрация по датам и диапазонам
- Агрегация (GROUP BY, HAVING)
- CTE (Common Table Expressions)
- Оконные функции (ROW_NUMBER)
- Подзапросы
- Логика просрочки и платежей
- Выбор последнего события в группе
