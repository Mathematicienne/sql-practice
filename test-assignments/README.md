## Как использовать

Каждая папка содержит:
- `schema.sql` — `CREATE TABLE` + тестовые данные
- `task_*.sql` — решения с условиями в комментариях

Для воспроизведения:
```bash
cd test-assignments/loan_analytics
sqlite3 loan_test.db < schema.sql
sqlite3 loan_test.db < task_01.sql
```
