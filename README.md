# SQL Practice

SQL-запросы к открытым датасетам. Практика оконных функций, CTE, JOIN и задач с собеседований.

## Датасеты
- Superstore Sales (Kaggle)
- Brazilian E-Commerce (Olist, Kaggle)

## Что прокачиваю
- Оконные функции: ROW_NUMBER, RANK, LAG, LEAD
- CTE (WITH)
- Сложные JOIN
- Задачи с собеседований: дубликаты, топ-N, retention, скользящее среднее

## Структура
Каждый файл `.sql` содержит задачу в комментарии и решение.
