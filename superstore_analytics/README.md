# Superstore Analytics 🛒

16 аналитических SQL-запросов к учебной базе данных Superstore.  
Данные загружаются из CSV в SQLite через Python.

---

## 🗂 Структура

| Папка | Тема | Задачи |
|-------|------|--------|
| `01_row_number/` | Нумерация строк в группах | 2 задачи |
| `02_rank_dense_rank/` | Ранжирование агрегированных данных | 1 задача |
| `03_lag_lead/` | Доступ к предыдущей/следующей строке | 2 задачи |
| `04_rolling_windows/` | Скользящие окна и кумулятивные суммы | 2 задачи |
| `05_analytics/` | Доли, сегментация, retention, поиск максимума | 5 задач |
| `06_basic_aggregation/` | Группировка, агрегация, выбросы | 4 задачи |

---

## 🚀 Быстрый старт

```bash
# 1. Установить зависимости
pip install pandas chardet

# 2. Загрузить данные из CSV в SQLite
python load_data.py

# 3. Подключиться к БД
sqlite3 superstore.db
```

```markdown
## 🛠 Стек

- **SQLite** — лёгкая БД для локальной практики
- **Python** — загрузка CSV через `pandas` + `chardet` для автоопределения кодировки
- **SQL:** оконные функции, CTE, агрегация, ранжирование, скользящие окна

## ⚠️ Примечания

- База `superstore.db` **не хранится в репозитории** — она генерируется скриптом `load_data.py`
- Исходный CSV-файл `Superstore.csv` также не включён (игнорируется через `.gitignore`)
- Для воспроизведения: скачай `Superstore.csv` из открытых источников → запусти `python load_data.py`
```
